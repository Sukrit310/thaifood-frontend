# ThaiFood Guide Implementation Plan

> **For agentic workers:** Use scoped parallel work with shared interfaces; read the user specification before implementation.

**Goal:** Deliver the specified ThaiFood Guide frontend with a contract-compatible mock and production fetch switch.
**Architecture:** CRA SPA, service layer, AuthContext and role guards, public/member/admin routes.
**Tech Stack:** React19, Router6, Tailwind3, CRA5, native Fetch, Jest/RTL.
**Spec:** docs/superpowers/specs/2026-11-12-thaifood-design.md and three root requirement documents.

## Global Constraints

- Keep CRA/react-scripts, process.env.REACT_APP_API_URL, port 3000, npm start/test/run build.
- API Contract v2 endpoints, camelCase fields and Thai-name filters are immutable.
- Reference repository is read-only; do not commit secrets or .env files.
- Mock data first; no actual Go URL has been supplied.

## Review Focus

- Expired/corrupt saved sessions: recover without crash or protected content flash.
- Ownership and roles: member cannot enter admin or delete others' reviews.
- Filter/page changes: URL and results agree, no stale request overwrite.
- Missing data and API failures: actionable loading/empty/error/retry states.
- Mutation integrity: review averages and cascade removal remain consistent.
